# References To Keep In Mind

This starter was created from the ContextOS / Checkpoint strategy discussion and the attached research report.

Key conclusions used:

- Position ContextOS as repo-native, tool-agnostic continuity infrastructure, not generic AI memory.
- Start with a local-first Markdown MVP.
- Use portable repo artifacts such as `AGENTS.md` and `CLAUDE.md`.
- Keep the first real win centered on cross-agent handoff and `checkpoint resume`.
