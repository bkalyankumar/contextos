# Project Summary

ContextOS is a persistent context operating system for AI-assisted software engineering.

Checkpoint is the developer-facing CLI for ContextOS.

The core problem:

AI coding agents lose continuity across sessions, tools, models, repos, machines, and workflows. Developers repeatedly re-explain architecture, decisions, conventions, current tasks, and constraints.

The product promise:

```text
Plan in Claude. Code in Codex. Debug in Claude Code. Delegate to Antigravity. Resume anywhere.
```

The MVP is local-first and Markdown-first. It should prove that a developer can move work between AI agents without reconstructing context manually.
