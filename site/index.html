Resume with enough context to move.

Not another coding agent. The continuity layer beneath them.

ContextOS keeps the durable project memory where the repo can own it: Markdown files, explicit tasks, handoffs, decisions, and projections that existing tools can read.

Local-first memory

Project context lives in `.contextos/`. User preferences live in `~/.contextos/about-me.md`. Both are plain text by default.

Agent-specific packs

Generate focused continuation packs for Codex, Claude, Claude Code, Antigravity, Cursor, or a generic agent.

Durable handoffs

Every meaningful work session can leave a handoff with status, files changed, tests run, blockers, decisions, and a continuation prompt.

Install from source for early testing.

The first public release proves the local workflow. PyPI packaging, hosted sync, dashboards, and IDE extensions are intentionally later. 

git clone git@github.com:bkalyankumar/contextos.git
cd contextos
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'

checkpoint setup-user
checkpoint init
checkpoint status
checkpoint continue
