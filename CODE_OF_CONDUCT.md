# Code Of Conduct

ContextOS should be a useful place for serious builders to improve AI-assisted
engineering workflows together.

## Expected Behavior

- Be direct, specific, and respectful.
- Assume good intent, but do not ignore harmful impact.
- Keep criticism focused on code, docs, behavior, and user outcomes.
- Welcome new contributors without lowering the quality bar.
- Protect private information, credentials, and non-public company context.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks
- Publishing private credentials, logs, URLs, or user data
- Repeated off-topic comments that derail maintainers or contributors
- Bad-faith reports, spam, or intentionally misleading reproductions

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or
limit participation when behavior harms the project or its contributors.

If you need to report conduct concerns, use the same private channel described
in `SECURITY.md` when privacy matters. Keep reports factual and include links or
timestamps when available.
