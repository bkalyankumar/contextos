# Coding Standards

- Use Python 3.10+.
- Use Typer for the CLI.
- Keep functions small and readable.
- Prefer standard library unless a dependency adds clear value.
- Write tests for core command behavior.
- Do not silently overwrite user-authored context files.
- Create parent directories before writing files.
- Treat Markdown files as durable user data.
- Avoid hidden magic in the MVP.
