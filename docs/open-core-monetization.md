# Open-Core Monetization Plan

## Rule

Open-source the local continuity layer.
Monetize sync, teams, governance, and enterprise trust.

## Open source

- Checkpoint CLI
- `.contextos/` schema
- local resume packs
- local handoffs
- local task files
- local `about-me.md`
- `AGENTS.md` and `CLAUDE.md` projections
- local encrypted export/import
- basic adapters for Codex, Claude Code, Cursor, Windsurf, Antigravity
- local MCP server eventually

## Paid Pro

- encrypted Context Vault
- multi-machine sync
- automatic backup/restore
- device pairing
- background sync daemon
- context snapshots
- cross-device resume
- advanced agent profiles

## Paid Team

- shared team memory
- shared project vault
- shared agent instructions
- onboarding packs
- team handoff timeline
- GitHub/GitLab integration
- Slack/Teams notifications
- team permissions

## Enterprise

- self-hosted vault
- SSO/SAML/OIDC
- SCIM
- audit logs
- retention policies
- legal hold
- BYOK
- data residency
- policy engine
- secret/PII redaction policies
- admin dashboard
- priority support/SLA
