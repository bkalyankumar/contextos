# Checkpoint 0.1.0

Checkpoint 0.1.0 is the first public local-first CLI release for ContextOS.

ContextOS is repo-native continuity infrastructure for AI-assisted software
engineering. Checkpoint creates readable Markdown project memory, task files,
handoffs, and continuation packs so work can resume across coding agents without
manual recap.

## Highlights

- Added `checkpoint setup-user`, `init`, `status`, `resume`, `continue`,
  `handoff`, `detect-agent`, and `show`.
- Added agent-specific context packs for Codex, Claude, Claude Code,
  Antigravity, Cursor, and generic fallback.
- Added durable Markdown task files and handoff files.
- Added local event logging for continuity metadata.
- Added final redaction for generated continuation output.
- Added Apache-2.0 licensing, contribution guidance, security policy, code of
  conduct, CI, and launch documentation.

## Install

The first release supports source install for contributors and early testers:

```bash
git clone git@github.com:bkalyankumar/contextos.git
cd contextos
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
checkpoint continue
```

Packaged distribution is intentionally deferred until external feedback confirms
the right package name and support expectations.
